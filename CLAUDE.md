# The Prophet — site
Front end of theprophet.fun. Static HTML + CSS, mobile first, handed to the CTO who drops it into Rust server templates. No React, no framework, no build step, no npm. Vanilla JS only for nine things: carousel swipe/selection, menu button, first-visit walkthrough (remembered on device), typewriter placeholder, roadmap timeline light, contract-address copy button, the $PROPHET price chart, the small tab/toggle controls (filters, ranges, Price/MCap, vote popups), and the circuit board behind the prompt bar. Everything the server fills in is a clearly marked template variable, written as {{name}} until the CTO's syntax is confirmed; list every variable used in TEMPLATE_VARS.md.

## Files
site/index.html (home) · prophecies.html · prophet.html · partials/header.html, below-fold.html, footer.html · styles.css · app.js · assets/. Mock data inline: 12 sample markets, a few sample theses, one sample Record entry. Partials are canonical in site/partials/. Each page carries a copy wrapped in <!-- partial:header --> ... <!-- /partial:header --> markers so the CTO replaces them with server includes. Repeated rows (markets, takes) have one template-variable copy inside a <template> element so it never renders from disk; the server loop replaces the <template>. All asset paths are relative so pages open directly from disk; the CTO may rewrite to absolute on his server.

## Brand
Colors, max four: navy #151B26 (canvas), deep purple, glow green, off-white. Orbitron 500, all caps, letterspaced for wordmark and headings. Space Grotesk for body and UI. Logo flat with no glow. No orb or crystal ball anywhere. Flat, thick outlines, esports-badge feel. Wordmark and logo come from assets/, never typed as text.

## Style
Reference: orbmarkets.io on our palette. Canvas #151B26, flat — no grid, no pattern, no texture. Behind the prompt bar only, inside the hero, desktop (1024px+): a circuit board. Traces leave the bar's frame at 90 degrees, never off a corner, run straight, turn at right angles and end in a small square pad. Two to four legs, no diagonals, no curves, nothing joins into a web, nothing is drawn over text or a card, and nothing rises above the top of the cards. Invisible at rest. Every 3 seconds the bar's frame swells and exactly one trace lights: a 160px green streak in the roadmap's language, peaking at 0.5 against its 0.9, with the pad filling as the light lands and draining behind it. A fresh route is generated for every flash by a self-contained route planner, which owns shape and length: a route may only move in one horizontal and one vertical direction so it can never double back, its length is drawn from weighted classes so runs are not all long, and it takes one of five shapes. Runs go far, up to 950px, at the roadmap's own 200px/s, with climbs that zigzag up the channel between the carousel's arrow and its cards, never passing the arrow, and never the same side of the bar three times running; a long one is still travelling when the next flash fires and that is fine, so at most two are on screen. What never varies is the beat: exactly one trace leaves the bar per flash. Traces are bounded by the hero on all four sides, so nothing runs off the page. Console: window.prophetBoard.set({beat, speed}). Nothing renders below 1024px or on any page without a prompt bar. Every panel, row, card, and input has a 1px outline in off-white at ~15% opacity; no fills, no gradients, no shadows, no rounded corners beyond 4px. Green is the only accent: status dot, active nav, YES tallies, links, send button. The Vote button is the one purple control, matching the vote state it belongs to. Purple only in the logo, the hero glow (deep #5F3A8B), and draft/vote text (brighter #B08CF5 so it reads on navy). Vote tallies read "62% YES" with the tally colored green for YES, red for NO; never "by weight". Numbers in tabular figures. Orbitron 500 caps letterspaced for the wordmark and section headings; Space Grotesk for everything else. Dense, sleek, wireframe; it should feel like an agent's terminal, not a marketing page.

## Hard rules
Zero crypto-speak. Never show a wallet address; people have usernames. No calendar dates anywhere; times are relative. Losses shown next to wins. Where copy needs the character's voice (empty states, walkthrough cards, signed-out label), write [COPY] placeholders; never invent copy. Never add features, sections, or mechanics not in this file; if something seems missing, stop and ask. Small diffs, one step per prompt, explain each change in one line.
